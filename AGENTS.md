# AGENTS.md

The rules that used to live in this file — one flat list of 68 bullets, 56 KB,
too large to load and too unstructured to search — are now in
[`docs/design/`](docs/design/00-index.md), split by subject, each with a stable
ID. Nothing was dropped: one pair of rules was merged (a prohibition and its own
sanctioned exception, which had drifted into two entries), and one rule that two
others had been citing as law was finally written down.

**Start here:** [`CLAUDE.md`](CLAUDE.md) — the invariants that hold in every
session, and the map of which rules file covers what.
